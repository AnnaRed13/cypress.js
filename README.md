## Описание проекта и задачи
Автоматизировать часть проверок авторизации с помощью Cypress

## Тест-кейсы, которые автоматизировали
* Авторизация с верным паролем и верным логином
* Авторизация c неверным логином и неверным паролем
* Авторизация c верным логином и верным паролем
* Проверка флоу восстановлением пароля

## Детали реализации

1. baseUrl вынесен в переменные конфига

2. Применение хука beforeEach

3. Переменные данные для авторизации вынесены в отдельный файл

4. Отсутствуют node.modules
